# Contributing

Open an issue for compatibility problems or a pull request for focused improvements. Use synthetic identifiers and records in every test and example. Never submit credentials, tokens, customer data, private hostnames, logs from a real workspace, or JoinLayer deployment details.

Every change must keep the skill, tool schemas, gateway tests, and public documentation consistent. Run the documented validation commands before requesting review. Security reports belong in the private channel described in `SECURITY.md`, not in issues or pull requests.

Contributions are reviewed but never deployed automatically to JoinLayer infrastructure.
