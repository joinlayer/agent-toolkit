# Public And Hosted Source Synchronization

The hosted JoinLayer MCP gateway is built and deployed by the private JoinLayer platform release system. Its `mcp-gateway/` tree must nevertheless match a tagged release of this public repository exactly.

For every hosted gateway release:

1. Update the public gateway source, dependency locks, schemas, and gateway tests in the same release train as the private integration.
2. Pass public tests, snapshot safety checks, dependency review, and focused security review.
3. Tag the reviewed public toolkit revision.
4. Pin that public repository URL, tag, commit, and normalized source-tree digest in the private platform release metadata.
5. Recompute the digest from the private build context and fail the platform release if it differs.
6. Build and attest the deployable gateway image only after the equality check succeeds.
7. Record the public toolkit tag and commit in the hosted image labels and JoinLayer release manifest.

Normalization excludes only repository metadata and generated bytecode declared by the public snapshot contract. It never excludes executable gateway source, dependency locks, schemas, or gateway tests. Skills, plugin manifests, prompts, use cases, and repository documentation have their own versioned distribution and validation contract; they are not part of gateway byte equality.

Before either side is committed, maintainers can verify two local checkouts in
either direction:

```bash
python scripts/source_tree_digest.py --compare-root /path/to/private-platform
```

The command prints both normalized gateway digests and fails when the file
count or digest differs. The private release runs the equivalent check against
the pinned public toolkit revision; a digest copied by hand is not sufficient.

The private repository contains the skill mirror, control-plane integration, and deployment configuration that are intentionally outside byte equality. None of those files may replace, patch, or override public gateway code during image construction.

The private skill mirror keeps a deployment URL placeholder so the hosted
gateway can package the correct endpoint for each environment. The public
skill uses the canonical production URL. Public gateway contract tests run in
a temporary fixture that changes only this distribution value; the committed
gateway test and source trees remain untouched and covered by the digest.

An emergency gateway security fix follows the same sequence. It may be reviewed and released on an accelerated path, but it must be published and pinned before the corrected hosted image is deployed.
